# Рекордер звука (SoundCatcher)

Android-приложение: записывает звук, который воспроизводит телефон (музыка, видео, игры), сразу в **MP3** и умеет **обрезать** записи по длине.

## Как собрать на GitHub

1. Создайте репозиторий на github.com и загрузите в него **всё содержимое этой папки** (вместе со скрытой папкой `.github`).
   Через git: `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <URL> && git push -u origin main`.
2. Вкладка **Actions** → workflow **Build APK** (запускается сам при пуше; либо **Run workflow** вручную).
3. Когда сборка позеленеет, откройте её и внизу в **Artifacts** скачайте `SoundCatcher-debug-apk`. Внутри zip лежит `app-debug.apk`.
4. Установите APK на телефон (разрешите установку из неизвестных источников).

Сборка идёт без gradle-wrapper: в workflow подключается Gradle 8.9, JDK 17, NDK 27 и CMake ставятся через sdkmanager.

## Как пользоваться

- Режим **«Системный звук»**: Начать запись → Android спросит разрешение на захват → включайте музыку или видео в любом приложении. Остановить можно в приложении или кнопкой «Стоп» в уведомлении.
- Режим **«Микрофон»**: запись с микрофона (для разговора по громкой связи).
- Записи сохраняются в «Музыка/SoundCatcher» (видны в любом плеере). В списке: прослушать, **обрезать**, отправить, удалить.
- Обрезка: два ползунка задают начало и конец, есть предпрослушивание. Результат сохраняется отдельным файлом `имя_cut.mp3`, оригинал не трогается (обрезка = декодирование + повторное кодирование LAME).

## Ограничения Android

- Захват системного звука работает на Android 10+ и только для приложений, которые его не запретили. Некоторые сервисы (часть стриминговых и защищённого контента) выдают тишину.
- **Звук телефонного разговора и голосовых чатов сторонние приложения напрямую записать не могут** — это запрет системы, не ошибка приложения. Обходной путь: громкая связь + режим «Микрофон» (качество хуже, слышно в основном то, что звучит из динамика и в комнате).
- Запись разговоров допустима только с согласия собеседников (законы разных стран отличаются).

## Состав

- `app/src/main/java/app/soundcatcher/` — Kotlin: `RecorderService` (захват + кодирование на лету), `Mp3Trimmer` (обрезка), `MainActivity`, `TrimActivity`, `Storage` (MediaStore).
- `app/src/main/cpp/` — JNI-обёртка и исходники кодировщика **LAME** (libmp3lame, лицензия LGPL).
